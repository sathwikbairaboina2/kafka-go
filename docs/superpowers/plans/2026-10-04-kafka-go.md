**Goal:** Ship kgod, a single-binary Kafka broker in Go (standard library only), that franz-go v1.22.1 and
kcat 1.7.1 produce to, consume from and run consumer groups against, with a crash-safe segment log, a kill -9
crash loop, and a measured throughput comparison with Apache Kafka 4.3.1.

**Architecture:** `internal/server` reads size-prefixed frames per connection, parses the request header and
gates the version against one table. `internal/broker` decodes the body (`internal/protocol`), calls the log
(`internal/storage`), topic metadata (`internal/meta`) or the group coordinator (`internal/group`), and encodes
the response. Record batches are validated (`internal/record`) and stored verbatim. `internal/app` wires it all
for `cmd/kgod`, the compat tests and the crash harness.

**Tech stack:** Go 1.26 via Docker image `golang:1.26` (verified `go1.26.8 linux/amd64`). Broker: standard library
only. Tests and tools: `github.com/twmb/franz-go v1.22.1`, `github.com/twmb/franz-go/pkg/kmsg v1.14.0`,
`pgregory.net/rapid v1.3.0`. Docker images: `apache/kafka:4.3.1`, `edenhill/kcat:1.7.1`,
`gcr.io/distroless/static-debian12:nonroot`. All versions checked to exist on 2026-10-04.

## Review focus (the reviewer will check these first)

1. **Batch validation before append.** A corrupt batch must change nothing (`TestProduceRejectsCorruptBatch`).
2. **Torn tail recovery** truncates exactly at the end of the last valid batch and rebuilds the index
   (`TestRecoveryTruncatesTornWrite`, `FuzzRecoverSegment`).
3. **Fetch always returns at least one whole batch** when data exists, even above `max_bytes`, and never a partial
   batch otherwise (`TestFetchReturnsWholeBatches`).
4. **acks=0 produces no response** and does not break ordering (`TestPipelinedRequestsInOrder`).
5. **Stale generation commits are rejected and not persisted** (`TestCommitStaleGenerationRejected`).
6. **Long-poll wakeups are not lost**: the wait channel is taken before the read (`TestFetchLongPollWakesOnAppend`).
7. **No invented numbers** in README/DEVDOCS.

```go
// ErrShort is returned when a read needs more bytes than remain; ErrMalformed for invalid lengths.
var ErrShort = errors.New("protocol: short buffer")
var ErrMalformed = errors.New("protocol: malformed field")

// Reader decodes big-endian Kafka primitives. The first error sticks; later reads return zero values.
type Reader struct{ /* b []byte; off int; err error */ }
func NewReader(b []byte) *Reader
func (r *Reader) Err() error
func (r *Reader) Remaining() int
func (r *Reader) Int8() int8; Int16() int16; Int32() int32; Int64() int64; Uint32() uint32; Bool() bool
func (r *Reader) Uvarint() uint64          // unsigned LEB128, max 10 bytes
func (r *Reader) Varint() int64            // zigzag
func (r *Reader) String() string           // int16 length, -1 is ErrMalformed here
func (r *Reader) NullableString() *string  // int16 length, -1 -> nil
func (r *Reader) CompactString() string    // uvarint N+1
func (r *Reader) CompactNullableString() *string // 0 -> nil
func (r *Reader) Bytes() []byte            // int32 length; returns a sub-slice, not a copy
func (r *Reader) NullableBytes() []byte    // -1 -> nil
func (r *Reader) ArrayLen() int            // int32; -1 -> -1 (null); n > Remaining() -> ErrMalformed
func (r *Reader) CompactArrayLen() int     // uvarint-1; 0 -> -1 (null); n > Remaining() -> ErrMalformed
func (r *Reader) SkipTaggedFields()        // uvarint count, then (uvarint tag, uvarint size, bytes)*
func (r *Reader) Raw(n int) []byte

// Writer appends big-endian Kafka primitives.
type Writer struct{ /* b []byte */ }
func NewWriter(capacity int) *Writer
func (w *Writer) Buf() []byte
func (w *Writer) Int8(v int8); Int16; Int32; Int64; Uint32; Bool
func (w *Writer) Uvarint(v uint64); Varint(v int64)
func (w *Writer) String(s string); NullableString(s *string); CompactString(s string); CompactNullableString(s *string)
func (w *Writer) Bytes(b []byte); NullableBytes(b []byte) // nil -> -1
func (w *Writer) ArrayLen(n int)          // n < 0 writes -1
func (w *Writer) CompactArrayLen(n int)   // n < 0 writes 0, else n+1
func (w *Writer) EmptyTaggedFields()      // writes 0x00
func (w *Writer) Raw(b []byte)
```

Every array/length check must reject a length larger than `Remaining()` before allocating
(an element is at least one byte), so a hostile length cannot force a huge allocation.

- ListOffsets v2: -1 -> HW, -2 -> log start (response timestamp -1); other timestamps -> `OffsetForTimestamp`

### Task 19: Group state machine (pure core)

**Files:** create `internal/group/group.go`, `group_test.go`, `model_test.go`.

```go
type State int
const (Empty State = iota; PreparingRebalance; CompletingRebalance; Stable)
type Protocol struct{ Name string; Metadata []byte }
type JoinRequest struct {
	MemberID, ClientID              string
	SessionTimeout, RebalanceTimeout time.Duration
	ProtocolType                    string
	Protocols                       []Protocol
}
type MemberMeta struct{ ID string; Metadata []byte }
type JoinResult struct {
	Err        int16
	Generation int32
	Protocol   string
	Leader     string
	MemberID   string
	Members    []MemberMeta // only in the leader's result
}
type SyncResult struct{ Err int16; Assignment []byte }

// Group is not safe for concurrent use; Coordinator serialises calls. Replies may be invoked later
// (from Join, Sync, Leave or Tick) and each reply func is called exactly once.
type Group struct{ /* ... */ }
func NewGroup(id string, newID func() string) *Group
func (g *Group) Join(now time.Time, req JoinRequest, reply func(JoinResult))
func (g *Group) Sync(now time.Time, memberID string, gen int32, assignments map[string][]byte, reply func(SyncResult))
func (g *Group) Heartbeat(now time.Time, memberID string, gen int32) int16
func (g *Group) Leave(now time.Time, memberID string) int16
func (g *Group) Tick(now time.Time)
func (g *Group) ValidateCommit(memberID string, gen int32) int16
func (g *Group) State() State
func (g *Group) Generation() int32
func (g *Group) Members() []string // sorted
```

Rules (single source; tests and the model check these):
1. Join with empty `MemberID`: new id `ClientID + "-" + newID()`, record it as pending with a session deadline,
   reply at once `{Err: ErrMemberIDRequired, MemberID: id, Generation: -1}`.
2. Join with an id that is neither a member nor pending -> `ErrUnknownMemberID`. `ProtocolType` different from a
   non-empty group's -> `ErrInconsistentGroupProtocol`. No protocol shared with all members -> same error.
3. Accepted join: store protocols, `lastHeartbeat = now`, keep `reply` as the member's pending join. If the state
   is Empty, Stable or CompletingRebalance, go to PreparingRebalance with
   `deadline = now + max(RebalanceTimeout of members)`; pending syncs get `ErrRebalanceInProgress`.
4. The join phase completes as soon as every member has a pending join, or in `Tick` once `now >= deadline`
   (members without a pending join are removed). Completion: `Generation++`; protocol = the first protocol of the
   earliest-joined member that every member lists; leader = the old leader if still a member, else the
   earliest-joined member; state CompletingRebalance; every pending join gets its result, the leader's with all
   members' metadata for the chosen protocol (in join order). If no members remain: state Empty.
5. Sync: unknown member -> 25; `gen != Generation` -> 22; PreparingRebalance -> 27. CompletingRebalance: a follower's
   reply waits; the leader's call stores `assignments`, moves to Stable and replies to every waiting sync and itself
   with each member's bytes (missing -> empty). Stable: reply at once with the stored assignment.
6. Heartbeat: unknown -> 25; gen mismatch -> 22; PreparingRebalance -> 27; otherwise 0. Always refresh `lastHeartbeat`
   for a known member.
7. Leave: unknown -> 25; remove the member (a pending join for it gets `ErrUnknownMemberID`); if members remain go
   to PreparingRebalance (and complete at once if all remaining have pending joins); else Empty.
8. Tick: remove members whose `now - lastHeartbeat > SessionTimeout` and who have no pending join, and pending ids
   past their deadline; removals trigger rule 7's transition. Then apply rule 4's deadline.
9. ValidateCommit: `gen < 0 && memberID == ""` -> 0 only when Empty, else 22; unknown member -> 25;
   `gen != Generation` -> 22; CompletingRebalance -> 27; else 0.
